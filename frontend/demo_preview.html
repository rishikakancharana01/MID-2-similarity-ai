The NLP Semantic Pipeline

Sentence Transformers convert texts into 384D vectors; scikit-learn computes cosine similarity.

Mathematical Cosine Formula

cos(θ) = ( A · B ) / ( ||A|| × ||B|| )

Evaluates the angle between vector A (the question) and vector B (each passage). Because vectors are normalized, dot product directly computes the cosine distance.

Academic Distinction

Similarity ≠ Factuality: Cosine similarity measures semantic relatedness. A high score means the document discusses the query topic, not that the answer is guaranteed factually true.

Overlapping windows (100 words with 25-word overlap) prevent context loss across paragraph boundaries.
